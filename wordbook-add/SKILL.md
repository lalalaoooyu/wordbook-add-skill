# 记生词和句子到「我的生词本」

生词本是一个已发布的 Artifact，数据存在它的数据库里：

- 链接：WORDBOOK_URL
- 集合：`words`（单词和句子都存在这里，用 `type` 区分）
- 用 `ArtifactData` 工具写入（没加载就先用 ToolSearch 加载 `select:ArtifactData`）。

不要重新发布页面，也不要新建 artifact，只往数据库里加记录。

## 第一次使用：建生词本

如果上面的链接还是 `WORDBOOK_URL`（说明还没建生词本），第一次要写入时：

1. 读本 skill 文件夹里的 `wordbook.html`，用 Artifact 工具把它发布成新页面，`icon` 用 `book`，并加上数据库权限：
   `capabilities: {"db":{"rules":[{"path":"","read":"view","write":"owner"}]}}`
2. 把得到的链接告诉用户，请用户到 Customize > Skills 里打开这个 skill，把 `WORDBOOK_URL` 换成这个链接（这样以后每次都写进同一本）。
3. 这一次先用新链接把内容写进去。

只建一次。用户说已经有生词本时，请用户把链接发过来，不要另建。

## 先提议，等用户同意再写

**不要自动写入，也不要每次都去读生词本。先提议，用户说加了再加。**

用户问单词、句子、让你改句子时：

1. 正常回答问题，**这一步不调用任何生词本工具**。
2. 在回复最后加一行提议，列出值得记的内容，比如：`要加进生词本吗？covered by insurance、I chose high-quality…`
   - 只提议真正有用的：新词、好用的搭配、改正后的句子。基础词、闲聊里没改什么的句子不提。
   - 没有值得记的就不提议。
3. 用户回复「加」「好」「记一下」「yes」等同意，就把提议的内容写入；只选了一部分（「只加第一个」）就只写那部分。没回应或说不用，就不写。
4. 用户主动说「帮我记一下 ××」时直接写入，不用再问。

写入时：

- 不用事先查重；单词用固定的 `doc_id`，重复时会被拒绝写入（已存在的文档需要 if_version），这时告诉用户「生词本里已经有了」即可。
- 多条用 `batch`。
- 写完回一行：`已记入生词本：<内容1>、<内容2>`。

句子有错时，记**改正后的自然说法**，并在 `tip` 里写一句原来错在哪里。

`doc_id`：
- 单词：`en-<小写单词，空格换成->` 或 `ja-<罗马字>`
- 句子：`en-s-<当前时间 yyyymmddHHMMSS>` 或 `ja-s-<同左>`

## 字段

### 单词（`type` 可省略或写 `"word"`）

| 字段 | 英语 | 日语 |
|---|---|---|
| `lang` | `"en"` | `"ja"` |
| `word` | 单词或短语 | 写法（有汉字就用汉字） |
| `reading` | **只用美式** IPA，如 `/ˈkævəti/` | 假名 + 罗马字，如 `なつかしい (natsukashii)` |
| `speak` | 可省略 | 可省略；汉字读音容易被读错时填假名 |
| `zh` | 简短中文意思 | 简短中文意思 |
| `ex` | 一个简单、自然的例句 | 一个简单、自然的日语例句 |
| `exzh` | 例句的中文翻译 | 例句的中文翻译 |
| `tip` | 一条记忆点：拼写陷阱、词根、常用搭配或反义词 | 一条记忆点：用法、语感、常见搭配 |
| `added` | 当前时间，ISO 格式，带用户所在时区（如 +09:00） | 同左 |

### 句子（`type: "sentence"`）

| 字段 | 英语 | 日语 |
|---|---|---|
| `type` | `"sentence"` | `"sentence"` |
| `lang` | `"en"` | `"ja"` |
| `word` | 完整句子（自然、正确的版本） | 完整句子 |
| `reading` | 省略 | 全句假名读音（含难读汉字时必填） |
| `speak` | 省略 | 可省略；汉字容易被读错时填全句假名 |
| `zh` | 中文翻译 | 中文翻译 |
| `tip` | 一条要点：关键语法、好用的搭配、或原句错在哪 | 一条要点：语法、敬语等级、或原句错在哪 |
| `added` | 当前时间，ISO 格式，带时区 | 同左 |

句子不需要 `ex` / `exzh`。

## 注意

- 英语发音一律按美式，不写英式音标。
- 例句要短、日常，适合朗读。
- 改记录时先 `get` 拿到 `version`，再带 `if_version` 用 `update`。
- 删除前先跟用户确认。
- 写入失败时告诉用户这次没记上。
